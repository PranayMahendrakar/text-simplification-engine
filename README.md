# 📖 Text Simplification Engine

Convert complex academic content into more accessible language.

**Author:** Pranay M

## Features
| Module | Description |
|--------|-------------|
| Complexity Analyzer | Analyze text complexity |
| Vocabulary Simplifier | Simplify vocabulary |
| Sentence Splitter | Break complex sentences |
| Jargon Replacer | Replace technical jargon |
| Readability Scorer | Score readability |
| Concept Explainer | Explain complex concepts |
| Summary Generator | Generate simple summaries |
| Accessibility Checker | Check accessibility |
| Format Adapter | Adapt formatting |
| Export Manager | Export simplified text |
